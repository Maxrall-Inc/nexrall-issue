# Nexrall Code — Issue Tracker

Public bug & feature tracker for **Nexrall Code**, the autonomous AI coding agent for VS Code and the terminal.

| Where | Link |
| --- | --- |
| VS Code / Cursor / VSCodium (Open VSX) | https://open-vsx.org/extension/Maxrall/nexrall-code-for-vscode |

| Website | https://nexrall.com |

## Open an issue

[**New issue ->**](https://github.com/Maxrall-Inc/nexrall-issue/issues/new/choose)

Please include:

- **Version** — the extension version from the Extensions view, or `nex --version` for the CLI
- **Environment** — OS and editor (e.g. macOS 15, VS Code 1.105)
- **What you did / expected / got** — steps to reproduce if you can
- **Logs or screenshots** — extension: Output panel -> *Nexrall Code*; CLI: run with `--debug`

## Please redact

API keys, tokens, `.env` contents or any other secrets — before pasting logs or screenshots.

For anything security-sensitive, contact us via [nexrall.com](https://nexrall.com) instead of opening a public issue.

## Notes

- This repository hosts **issues and release downloads only**. The Nexrall Code source is developed in private repositories and is not mirrored here.
- The `nexrall-code-vscode.vsix` download link above always points at the newest release.
